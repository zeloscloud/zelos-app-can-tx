# CAN Transmit

Send CAN frames from the Zelos desktop app — pairs with the
[`zeloscloud.zelos-extension-can`](https://github.com/zeloscloud/zelos-extension-can)
agent extension.

- 🛰️ Pick an agent + bus
- ✏️ Compose a frame (raw bytes or DBC message + signals)
- 📤 **Send** one-shot or 🔁 **Start** a periodic
- ⏹️ **Stop** or 🗑️ delete the row
- 📊 Watch live tx counters per bus
